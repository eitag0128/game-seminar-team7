# Puzzle / 7班 ブラウザデモ

既存の Team7 リポジトリを使う、Three.js + TypeScript + Vite の独立アプリです。リポジトリ直下の Unity プロジェクトは変更していません。開発場所は `D:/ゲーム制作/ゲーム制作演習/game-seminar-team7/web-demo`。

## Windows / Mac から起動

Node.js 24 を推奨（最小22.18）。既存の作業を保存し、Git の状態を確認してからリポジトリを fast-forward で更新してください。

```sh
# リポジトリ直下で実行
git status --short
git pull --ff-only
cd web-demo
npm ci
npm run dev
```

表示された `http://127.0.0.1:5173/` をPCブラウザで開きます。Windows の PowerShell / Mac のターミナルで同じ npm コマンドが使えます。終了は Ctrl+C。5173番ポートが使用中なら、他の作業を停止せず `npm run dev -- --port 5174` 等で変更します。

`index.html` のダブルクリックでは起動しません。Unity Hub で開く必要もありません。`node_modules` は端末ごとに `npm ci` で作成します。

## 操作

- 起動時の「遊び方」で、移動・自販機の調べ方・鏡パズルの選び方・クリア後の進路を確認し、「街を歩く」で開始。画面下の「遊び方」で再表示できます。説明中は移動を止めます。
- 街の画面下には、現在の進行に応じて次の操作が表示されます。パズル画面にも、鏡の左右反転と「左側の缶の下のボタンを押す」という説明を表示します。
- `←` / `→` または `A` / `D`: 左右に歩く。ジャンプなし。
- 自販機に近づいてクリック: 拡大パズル。左右の飲料を鏡として見比べ、違う色の飲料のスイッチを押す。
- 誤答: 何も起こらない。`×` / `Esc`: パズルを閉じる。
- 正解: 自販機を修復し、記憶の断片を1個取得。「街へ戻る」後、右へ進むとループせず先の道へ到達。
- デモ終了画面で「もう一度歩く」: 初期状態から再プレイ。
- 画面下の「音 オン/オフ」: 雨音と効果音の切替。最初のクリックかキー入力で雨音が始まります（ブラウザの自動再生制限のため）。

## 発表モード（授業デモ用）

`http://127.0.0.1:5173/?mode=present` で開きます。仕様書の「問題の説明はほとんどなく、雰囲気で分かるデザイン」を試すモードです。通常モード（URLに何も付けない）は従来どおりの初見向け説明です。

- 起動時は「遊び方」ではなくタイトル「歩きはじめる」だけ。画面下の次の行動案内とパズル内の説明文を出しません。
- 画面下の「遊び方」は残してあり、詰まった時の保険として通常の説明を開けます。
- パズルを開いて12秒たつと鏡側の違う缶がかすかに明滅し、24秒で「……鏡の中で、ひとつだけ色が違う。」と表示（`src/config.ts` の `presentHintSeconds` / `presentMurmurSeconds`）。誤答には反応しないPM回答⑤を守るため、ヒントは時間経過だけで出します。
- 記憶取得後の案内も操作説明ではなく独白にしています。

両モード共通で、ループに気づけるよう次の変化があります（`src/loopEcho.ts`）。

- ループのたびに画面が一瞬青く明滅し、低いうなりの音と独白（「……また、同じ場所。」→「さっきも、ここを通った気がする。」→…→「この街は、何かが欠けている。」）。
- ループのたびに看板の文字が1文字ずつ消える（例: 「古書　雨音」の「雨」）。
- 2回目のループから、同じ黒猫が自販機を見つめて座る。
- 自販機に初めて近づくと「この自販機、どこか欠けている。」

## 検証・ビルド

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

`npm run build` は型検査後に `dist/` を生成します。`npm run preview` でビルドをローカル確認できます。静的配信にも使える相対パス設定ですが、外部への公開・GitHub Pages設定は今回行っていません。

ブラウザ試験はPlaywright Chromiumで通常のキー入力とクリックを使います。`test-results/` に画面を保存し、失敗時はtraceも残します。通常は Playwright 管理ブラウザを使用。既存のローカルChromiumを使う必要がある時だけ `PUZZLE_CHROMIUM_PATH` に実行ファイルのパスを渡せます。設定値やパスを他端末へ固定しないでください。

Three.jsを含む現在のJSは約576KB（gzip約148KB）で、Viteの500KB警告が出ます。起動・ビルド失敗ではありません。正式アセット投入時に読み込みサイズを再評価します。
