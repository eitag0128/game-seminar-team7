# Puzzle / 7班 ブラウザデモ

既存の Team7 リポジトリを使う、Three.js + TypeScript + Vite の独立アプリです。リポジトリ直下の Unity プロジェクトは変更していません。開発場所は `D:/ゲーム制作/ゲーム制作演習/game-seminar-team7/web-demo`。

## いちばん簡単な起動（URLを開く）

GitHub Pages で公開しています。ブラウザで開くだけです。

https://eitag0128.github.io/game-seminar-team7/

`web-demo/` を変更して main に push すると、`.github/workflows/pages.yml` が試験・ビルドして数分で自動更新します。結果はリポジトリの Actions タブで確認できます。リポジトリは公開設定なので、このURLも誰でも開けます。

## ネットがない時（ダブルクリック）

リポジトリ直下の `play/Puzzle.html` をダブルクリックすると、既定のブラウザで開いて遊べます。Node.js・`npm`・開発サーバーは不要で、ネット接続も要りません。USBメモリ等でHTMLファイル1つだけ渡しても動きます。

`src/` を変更したら、このフォルダーで `npm run play` を実行してHTMLを作り直し、一緒に commit してください（ビルド後、JS と CSS をHTMLに埋め込みます。`scripts/make-play.mjs`）。

## 開発用の起動（Windows / Mac）

Node.js 24 を推奨（最小22.18）。既存の作業を保存し、Git の状態を確認してからリポジトリを fast-forward で更新してください。

```sh
# リポジトリ直下で実行
git status --short
git pull --ff-only
cd web-demo
npm ci
npm run dev
```

表示された `http://127.0.0.1:5173/` をPCブラウザで開きます。Windows の PowerShell / Mac のターミナルで同じ npm コマンドが使えます。終了は Ctrl+C。5173番ポートが使用中なら、他の作業を停止せず `npm run dev -- --port 5174` 等で変更します。

`index.html` のダブルクリックでは起動しません。Unity Hub で開く必要もありません。`node_modules` は端末ごとに `npm ci` で作成します。

## ステージ1の遊び方

2026-11-01 から、プランナーのステージ1案（10/31 のメモ）を実装している。それまでの鏡パズルのデモは Git タグ `demo-mirror-puzzle-20261028` に残してある。

画面は左が現実の街、右が少女の頭の中（プランナー「1画面にした方がテンポ良くない？」）。縦長の画面では上が街、下が頭の中。

1. 頭の中に文が出る。文をクリック/タップすると次の行へ（待っていても進む）。読み終わると自販機を調べられる。
2. 自販機を調べると、頭の中に「？」の缶が浮かぶ。缶をクリックするたびに黄色い粒が1つ、上→右→下→左の順に飛ぶ。
3. もう一度自販機を調べて、コーンスープを選ぶ。ほかの飲み物は「それは好きじゃない。」とだけ言われる。
4. 頭の中の缶をクリックすると、缶から中身が注がれ、全部流れてしまう（排水口）。文を読み終わるとマンホールを調べられる。
5. マンホールはスライドパズル（3×3、空きマス1つ）。空きマスのとなりのパネルを押して動かし、蓋の模様をつなげる。
6. 頭の中に水がたまり、魚が顔を出して「宿題した？」「進路は―」としゃべる。文を読み終わると電柱を調べられる。
7. 電柱を調べると、頭の中で電柱が倒れて刺さる。電線の先を水までドラッグすると電気が流れ、魚が感電する（キーボードでは電線の先を選んで Enter）。
8. 文を読み終わったら、街の右端まで歩くとステージ1クリア。

謎を3つ解くまでは、街の端まで歩くと反対側の端に戻ってしまう（仕様書「何度進んでも同じところに帰って来てしまう」）。継ぎ目は見えず、初めて戻った時に「あれ、さっきの場所に戻ってる。」と出る。解いた謎はループしても残る。3つ解くとループが止まり、右端の先に通路が出る（左端は壁）。

- 歩く: `←` / `→` または `A` / `D`。スマホ・タブレットは左の画面の下の ◀ ▶ を押している間。ジャンプなし。
- 調べる: 物に近づくと「クリックして調べる」が出る。調べられるのは、その時に関係する物だけ。
- 起動時の「遊び方」で「音ありではじめる」か「音なしではじめる」を選ぶ。画面下の「遊び方」「音 オン/オフ」でいつでも見直し・切替できる。
- 左の画面には、今やることが1つずつ案内として出る。

| 少女 | デザイナー（山口さん）の待機画と歩き差分2枚（`src/assets/girl-*.png`）。歩く間は 歩き1→待機→歩き2→待機 を0.16秒ずつ切り替え |
| 文 | プランナーのメモの文をそのまま使用（`src/story.ts`）。案内文・「それは好きじゃない。」以外の一言・店名は仮 |
| 飲み物 | コーラ・お茶・コーヒー・オレンジ・ソーダ・コーンスープの6本（`src/config.ts`）。種類はプランナー未指定のため仮 |
| マンホールのパズル | 3×3、完成から4手ずらした配置（`src/slide.ts`）。模様は仮の花と波 |
| 位置・速さ | 街幅36、自販機 x=-10、電柱 x=1、マンホール x=10、速度4.6、調べられる距離2.7、文の間隔3.2秒（`src/config.ts`） |
| 音 | コンポーザー提供の効果音（`../materials/se` → `src/assets/se`）。雨・選択・足音・自販機・正解・間違い・ワープ。感電の音だけ素材がないので Web Audio で作った仮の音。自販機.mp3 は5回分入った13.7秒の素材なので、缶が落ちる部分（0.85〜1.5秒）だけ鳴らす（`src/audio.ts` の `CLIPS`） |
| ループと次の場所 | 謎を解くまでは両端がつながる。解いた後、右端の先の簡易通路を6進むとステージ1クリア。ステージ2は未実装 |
| 保存 | ページを読み込み直すと最初から。セーブは未実装 |

## 検証・ビルド

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

`npm run build` は型検査後に `dist/` を生成します。`npm run preview` でビルドをローカル確認できます。相対パス設定なので、同じ `dist/` を GitHub Pages でも配信しています（上記）。

ブラウザ試験はPlaywright Chromiumで通常のキー入力とクリックを使います。`test-results/` に画面を保存し、失敗時はtraceも残します。通常は Playwright 管理ブラウザを使用。既存のローカルChromiumを使う必要がある時だけ `PUZZLE_CHROMIUM_PATH` に実行ファイルのパスを渡せます。設定値やパスを他端末へ固定しないでください。

Three.js・少女の絵・効果音を含むJSは約1.9MBで、Viteの500KB警告が出ます。起動・ビルド失敗ではありません。正式アセット投入時に読み込みサイズを再評価します。
