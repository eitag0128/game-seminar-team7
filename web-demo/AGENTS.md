## 保存と共同作業

- 既存ファイル・資料は勝手に上書きしない。今回のブラウザ実装は `web-demo/` に隔離。Unity の Assets/Packages/ProjectSettings は触らない。
- 原本PDF、企画PPTX、会話HTML、資料画像はGドライブに保全し、GitHubへコピーしない。共有ログはGドライブに新しい日付入りファイルとして残す。
- `node_modules/`、`dist/`、テスト一時物、`.env*`、認証情報をGitへ入れない。依存バージョンは `package-lock.json` で共有し、別端末は `npm ci`。
- 検証済みの自分の変更だけを commit・push。競合や認証失敗を破壊的操作で回避しない。定期実行・監視を作らない。

## 確認手順

Node.js 24推奨（最小22.18）。このフォルダーで `npm ci`、`npm test`、`npm run build`。ブラウザ試験は `npx playwright install chromium` 後に `npm run test:e2e`。

通常起動は `npm run dev`。文を読み進める、自販機→粒→コーンスープ、注ぐ→排水、マンホールのパズル、電柱→電線を水へ、右端でクリア、再プレイを実際に確認する。進行（progression.ts）・頭の中の絵（brain.ts）・街の絵（street.ts）は別ファイルに保ち、絵の差し替えで進行が変わらないようにする。ビルド成功とプランナー/本人の受入は区別する。

引継ぎは `../docs/puzzle/HANDOFF_20261025.md`。案内文・店名・飲み物の種類・物の位置・移動速度・距離・頭の中と街の絵・次エリア・セーブなしは全て仮設定。ステージ1の記録は `../docs/puzzle/STAGE1_20261101.md`。
