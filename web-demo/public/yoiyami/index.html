選んだ紙片で、彼女の「これから」が変わる。

    夜の街の中を探索しよう

    街中に存在する「ちょっとした困りごと」や「出来事」に触れると、少女の性格を表す「紙片」を入手できます。集めた紙片はコラージュとして組み合わせることができます。使用した紙片によって少女の結末に変化が起こるかも…？

    1. 紙が浮かんでいる物に近づいて調べる。
    2. 出てきた選択肢から、少女ならどうするかを選ぶ。選んだ行動が紙片になる。
    3. 調べられるのは9回まで。住宅街・公園・学校の廊下は、道の端の看板から行き来できる。
    4. 9枚集まると少女のところへ戻り、紙片を並べてコラージュを作る。

    少女のコラージュ

    集めた9枚を並べて少女に渡します。どこに何を置くかで、少女の「これから」が変わります。置いた紙片を押すと手元に戻ります。
