## 実装した流れ

左が現実の街、右が頭の中（「1画面にした方がテンポ良くない？」）。

1. 頭の中の文（プランナーの文そのまま）→ 読み終わると自販機を調べられる。
2. 自販機を調べる →「自販機は眠らないから偉い？」、頭の中に「？」の缶。缶をクリックするたび黄色い粒が1つ、4方向に順番に飛ぶ。
3. 自販機でコーンスープを選ぶ。ほかは「それは好きじゃない。」（何も進まない）。
4. 頭の中の缶をクリック → 5本の缶から中身が注がれ、排水口から全部流れる →「まだ、よく分からないや」ほか。
5. マンホールを調べる → スライドパズル（3×3、空きマス1つ、完成から4手ずらし）。
6. 水がたまり、魚が顔を出して「宿題した？」「進路は―」→「あぁ、少し痛みは引いたかも」ほか。
7. 電柱を調べる → 頭の中で電柱が倒れて刺さる。電線の先を水までドラッグ → 感電、魚が死ぬ →「いいね」ほか。
8. 右端まで歩くと「ステージ1 クリア」。

追記（2026-11-02）: 最初は謎を解く前の右端で止めていたが、本人:「ループでも良くない？アイデアメモが仕様を上書きすることはないよ」。仕様書 06「何度進んでも同じところに帰って来てしまう」に従い、謎を3つ解くまでは両端がつながるループに戻した（初回に「あれ、さっきの場所に戻ってる。」）。解いた謎はループしても残る。3つ解くとループが止まり、右端の先の通路が見える。
