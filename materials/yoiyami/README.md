# よいやみの絵（デザイナー提供）

デザイナー（山口さん）が Discord の「２Dデザイナー」に上げた絵。ここのファイルは元データとして書き換えない。ゲームでは `web-demo/public/yoiyami/img/` に加工したものを置いて使っている。

## 今ゲームで使っているもの（2026-11-23〜）

| ファイル | 内容 | ゲームでの使い方 |
| --- | --- | --- |
| `yoiyami_idle_20261116_1.webp` 〜 `_3.webp` | 待機3枚（11/16。前の枝毛を消した版） | 64×64 のドット絵にして `yoiyami-idle1〜3.png` |
| `yoiyami_run_20261116_1.webp`, `_2.webp` | 走り2枚（11/16 の「最低限差分」） | 64×64 のドット絵にして `yoiyami-run1〜2.png` |
| `building_wide_20261120.webp` | 仮背景のビル（横長） | 余白を切って半分の大きさにし `building-wide.png`。住宅街とベンチで並べる |
| `building_tall_20261120.webp` | 仮背景のビル（縦長） | 同じく `building-tall.png` |
| `yoiyami_pixel_20261119.webp` | 山口さんのドット絵（11/19、ドット絵コンバータ＋手直し） | ドット絵の粗さの基準にした（キャラの高さ56マス）。ゲームには入れていない |

ドット絵への変換は、768×768 の絵を 64×64 のマスに分け、マスの中で塗られている割合が半分以上なら塗る、外側の輪郭は1マスの黒、そばかすの黄色が多いマスは黄色、という決まりで機械的に行っている。山口さんが手で描いたドット絵が届いたら、同じファイル名で差し替える。
